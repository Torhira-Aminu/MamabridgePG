# MamaCare PG

A maternal-health resource guide for Prince George's County, Maryland, built by the **MamaCare PG team**. It is a single static web page (HTML, CSS and JavaScript): open `index.html` in a browser.

Features: guided onboarding (pregnancy status, insurance, services needed), nutrition guidance, a resource directory filtered by category, events, and a help chat. English/Spanish toggle.

## Prototype notes
- The sign-in is a demo only; accounts live in page memory and the demo password is visible in the source. It is not a secure login.
- Resource names, phone numbers and eligibility figures should be re-verified before real-world use.
- Onboarding answers are not stored or sent anywhere.
